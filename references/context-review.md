# 全案脈絡與扣分前反證

首次評分前讀本頁。目的在於避免讀完文字後，仍把不同章節、時間或評量單位錯接；不是宣稱能保證完全理解。

## 先重建文件如何運作

完成全文及必要附件的讀取，才形成總評。分段閱讀時可記疑點，先標待回查，不急著定級。文字抽取、圖像讀取、版面檢查與外部查證各自記錄，不能互相冒充。

以短段落或小型對照表呈現：

- **用途與契約**：規劃、核定、執行或成果；對象、時間、限制從哪裡取得。自述與原始委託需求分開。
- **結構分工**：每章、附表或必要附件在整體流程中的作用，哪些只是總覽、哪些另有操作細節。
- **單位與層次**：誰做、誰被評或負責；個人、小組、班級不能互換，年級進程也不等於能力分組。
- **證據鏈**：課程的目標→共通教學→支援／分層→個人與合作證據→評量→回饋；其他表件改用目的→行動→回覆／核定→驗收。
- **未定與限制**：哪些是規劃者明示的待確認事項，哪些是評閱者尚未讀到；未知是否真的影響當前判斷。

摘要須反映該文件的具體內容，不只寫「已完整理解」。不用把每張表逐一重述，也不額外要求使用者批准摘要。

## 每個疑點都找能推翻它的證據

評閱者先回答下列問題，再決定問題是否成立及是否扣分：

1. **要求從何而來？**找原任務、已同意條件或文件自訂目標，不用個人偏好或鄰近另一任務代替。
2. **是否看對對象、階段與單位？**例如規劃案不能要求已有成效，個人任務卡不能代整組作品，摘要不必重複附件。
3. **其他地方是否已補足？**回查共同流程、進度、來源卡、教師支援、作品組合、評量說明、替代與裁決規則；記下位置與查到的內容。沒有反證也要記錄實際查過的相關範圍，不能只寫「無」。
4. **納入反證後還剩什麼？**撤銷誤判，或縮小為交叉引用／銜接不清；只有需要新增核心操作或評量設計時，才支持核心缺漏的結論。
5. **實際影響及級分如何成立？**用一名依現有指示操作的學生、教師或收件者作情境檢查。說清楚哪一步仍不能完成，及相鄰較高級為何不足以描述問題。嚴重程度與向度級分分別論證。

「缺少達標路徑」應檢查完整學習歷程與最後受評證據集合，而不是只找某張卡有沒有同樣的字句。小組可能整合不同成員的材料；不能要求每人獨立完成整組的來源數或產出量，除非契約確有此要求。仍須確認各人有達成個人核心能力的機會，不能以組員代答或組分證明個人理解。

## 裁決與處理

| 裁決 | 判斷依據 | 處理 |
|---|---|---|
| 已確認錯誤或設計缺漏 | 全文相關設計及反證都納入後，要求仍無法達成，或有可重現矛盾。 | 依實際影響及錨點定級，提出修改與驗收。 |
| 說明或銜接不清 | 已有可用設計，但引用位置、操作順序或評量單位不易辨認。 | 通常局部修訂或建議；若認定重大，須另證明其實際阻斷，不把「沒有重述」當證明。 |
| 待查 | 未取得相關資料、來源或必要附件，尚不能決定命題真假。 | 列待查；若影響整個向度可評性則保留未知，不以推測暗扣。 |
| 改進建議 | 現有設計已達契約，另一做法可能更清楚或方便。 | 不扣分，不把建議寫成必改或必備附件。 |
| 疑點已被反證解決 | 原文其他段落或裁決規則已明確處理。 | 撤銷批評；重要誤判可簡短交代回查結果。 |

## 定稿前再看一次

每項扣分都應能指出原文要求、支持證據、回查反證、仍未解決的功能影響及錨點。若刪除「希望更詳細」之類偏好後就沒有實質理由，改列建議或撤回。

不要用讀取段落數、頁數、計分程式通過或語氣自信，證明理解及評分正確。當使用者質疑脈絡時，回到原文驗證；若原判不成立，直接更正，不維護既定分數。
